# Migration Guide for Claude Opus 4.7

**Summary**: Documentation providing advice on upgrading from Opus 4.6 to Opus 4.7, focusing on token usage changes, effort level tuning, and planning for tokenizer updates.
**Source Context**: Referenced in https://www.anthropic.com/news/claude-opus-4-7, likely at https://platform.claude.com/docs/en/about-claude/models/migration-guide

---

## Purpose
Helps users plan for the transition to Opus 4.7 by addressing key changes: the updated tokenizer increasing token counts by 1.0–1.35×, and higher token usage at elevated effort levels (Source: https://www.anthropic.com/news/claude-opus-4-7). It includes recommendations for optimizing effort parameters and using task budgets.

## Key Topics
Covers token mapping adjustments, strategies for managing token consumption, and real-traffic measurement advice to ensure smooth migration.
