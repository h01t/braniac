# Claude Code

**Summary**: A coding platform from Anthropic that integrates Claude AI for assistance with programming tasks, featuring tools like slash commands and auto mode.
**Source Context**: https://www.anthropic.com/news/claude-opus-4-7

---

## Features with Opus 4.7
With the launch of Opus 4.7, Claude Code introduces new functionalities: the /ultrareview slash command for dedicated code reviews, and auto mode extended to Max users for autonomous task execution (Source: https://www.anthropic.com/news/claude-opus-4-7). Additionally, the default effort level is raised to 'xhigh' for all plans.

## Purpose and Usage
Claude Code is designed for developers to leverage Claude in coding environments, improving productivity through automated reviews and reduced interruptions. It is part of the broader ecosystem with [[entities/claude-platform-api.md]].
