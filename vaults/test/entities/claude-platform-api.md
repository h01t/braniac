# Claude Platform (API)

**Summary**: The API platform provided by Anthropic for developers to build applications using Claude models, with features like effort control and task management.
**Source Context**: https://www.anthropic.com/news/claude-opus-4-7

---

## Updates with Opus 4.7
The platform now supports higher-resolution image processing (a model-level change) and introduces task budgets in public beta for managing token spend across longer runs (Source: https://www.anthropic.com/news/claude-opus-4-7).

## Functionality
It enables integration of Claude AI into various services, allowing developers to control parameters like effort levels and token budgets. These features are crucial for optimizing performance and cost, especially with [[entities/claude-opus-4-7.md]].

## Related Concepts
Task budgets are a key addition, linked to [[concepts/task-budgets.md]] and [[concepts/token-usage.md]].
