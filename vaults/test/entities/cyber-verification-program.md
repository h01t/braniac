# Cyber Verification Program

**Summary**: A program launched by Anthropic alongside Claude Opus 4.7 that allows security professionals to apply for permission to use the model for legitimate cybersecurity purposes, bypassing its automated safeguards.
**Source Context**: https://www.anthropic.com/news/claude-opus-4-7

---

## Purpose and Context
The program is part of the safety framework established by [[concepts/project-glasswing.md]]. While [[concepts/claude-opus-4-7.md]] is released with safeguards that "automatically detect and block requests that indicate prohibited or high-risk cybersecurity uses," this program provides a pathway for authorized, legitimate use (Source: Anthropic News).

## Eligible Activities
The announcement invites "security professionals who wish to use Opus 4.7 for legitimate cybersecurity purposes (such as vulnerability research, penetration testing, and red-teaming)" to join the program (Source: Anthropic News).
