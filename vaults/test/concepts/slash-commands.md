# Slash Commands

**Summary**: Commands in Claude Code initiated with a slash, such as /ultrareview, to perform specific functions like automated code review.
**Source Context**: https://www.anthropic.com/news/claude-opus-4-7

---

## Overview
Slash commands are used in Claude Code for various tasks. With Opus 4.7, the new /ultrareview command produces a dedicated review session that flags bugs and design issues similar to a careful human reviewer (Source: https://www.anthropic.com/news/claude-opus-4-7).

## Availability
This feature is available to Pro and Max Claude Code users, with three free ultrareviews offered for trial. It enhances the coding experience by providing thorough, automated reviews.

## Context
Slash commands like /ultrareview are part of the broader updates in Claude Code with Opus 4.7, alongside [[concepts/auto-mode.md]] for autonomous task execution.
