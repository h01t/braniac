# Task Budgets

**Summary**: A feature on the Claude Platform that allows developers to set limits on token spending for AI tasks, enabling prioritization of work across longer runs.
**Source Context**: https://www.anthropic.com/news/claude-opus-4-7

---

## Introduction
Task budgets are launched in public beta with Claude Opus 4.7, providing a way to guide Claude's token expenditure on the API (Source: https://www.anthropic.com/news/claude-opus-4-7).

## Purpose
This feature helps manage resource allocation for extended tasks, ensuring efficient use of tokens and aligning with user priorities. It is related to [[concepts/token-usage.md]] and is part of the [[entities/claude-platform-api.md]] updates.

## Usage in Migration
During migration from Opus 4.6 to Opus 4.7, task budgets can be used to control increased token usage from the updated tokenizer and higher effort levels (Source: same).
