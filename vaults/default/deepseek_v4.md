# DeepSeek V4

DeepSeek V4 is an upcoming multimodal large language model from DeepSeek, expected to launch in early March 2026. It features native image, video, and text generation capabilities, a 1 million token context window, and is built on a trillion-parameter Mixture-of-Experts (MoE) architecture with Engram memory. It is optimized for domestic Chinese AI chips from Huawei and Cambricon. [[PixVerse]] plans to integrate it soon after release.
