# HTML Utilization in Perception

**Summary**: HTML utilization in perception involves capturing both visual features of a screenshot and the descriptions of associated HTML elements to obtain a robust representation of a visual interface.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf (citing [30]: DUALVCR)

---

HTML utilization is a method used by LLM agents to perceive GUI environments. Systems like DUALVCR [30] capture the visual features of a screenshot and the descriptions of associated HTML elements. This combination provides a robust representation of the visual screenshot, enabling the agent to understand the interface's structure and content.

This approach is similar to using the [[concepts/accessibility-tree-perception.md]], but it specifically leverages the HTML source code of web pages. It falls under the category of structured data perception, which is one of the perception approaches summarized in Table 1 of the source document.
