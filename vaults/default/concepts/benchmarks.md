# Benchmarks

**Summary**: Benchmarks are evaluation sets used to measure AI model performance in various tasks, such as software engineering and professional work.

**Source Context**: https://www.minimax.io/news/minimax-m27-en

---

## Software Engineering Benchmarks

### SWE-Pro

SWE-Pro is a benchmark for software engineering tasks. MiniMax M2.7 scored 56.22% on this benchmark, as reported in the blog post (Source: https://www.minimax.io/news/minimax-m27-en).

### VIBE-Pro

VIBE-Pro evaluates repo-level code generation. M2.7 achieved 55.6% on this benchmark (Source: https://www.minimax.io/news/minimax-m27-en).

### Terminal Bench 2

This benchmark tests deep understanding of complex engineering systems. M2.7 scored 57.0% (Source: https://www.minimax.io/news/minimax-m27-en).

## Professional Work Benchmarks

### GDPval-AA

GDPval-AA measures domain expertise and task delivery capability. M2.7 has an ELO score of 1495 on this benchmark (Source: https://www.minimax.io/news/minimax-m27-en).

### Toolathon

Toolathon tests the ability to interact with tools. M2.7 achieved 46.3% accuracy (Source: https://www.minimax.io/news/minimax-m27-en).

### MM Claw

MM Claw is an evaluation set based on OpenClaw tasks. M2.7 scored 62.7% accuracy (Source: https://www.minimax.io/news/minimax-m27-en).

## Machine Learning Benchmarks

### MLE Bench Lite

On MLE Bench Lite, M2.7 achieved an average medal rate of 66.6% in autonomous optimization tests (Source: https://www.minimax.io/news/minimax-m27-en).
