# Instruction Tuning

**Summary**: A fine-tuning method where a pre-trained language model is trained on a dataset of (instruction, response) pairs to improve its ability to understand and follow natural language instructions.
**Source Context**: Referenced in numerous papers including Wei et al. (2022), Iyer et al. (2022), and Wang et al. (2023).

---

## Purpose and Process
The goal is to align a general-purpose pre-trained model with user intent. The model is fine-tuned on collections of tasks formatted as instructions (e.g., "Write a summary of the following article:") and their desired outputs. This teaches the model to generalize to unseen tasks described via instructions, enabling **zero-shot** and **few-shot** capabilities [Source: [97]].

Datasets for instruction tuning can be generated by humans, crowdsourced, or synthesized using larger models (e.g., using GPT-4 to generate instructions and responses). This process is crucial for creating helpful and conversational AI assistants [[concepts/alignment.md]].

## Impact and Variants
Instruction tuning is a core technique behind models like Alpaca, Vicuna, and WizardLM [[entities/alpaca-model.md]]. Research explores scaling instruction datasets (Opt-IML), using symbolic tasks, and specialized tuning for domains like medicine (Huatuo) or code (WizardCoder) [Source: [97], [102], [162], [163], [164]].
