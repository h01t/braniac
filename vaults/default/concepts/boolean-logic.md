# Boolean Logic
Boolean logic involves operations on truth values: True and False. Key operations include "not", "and", and "or", with a specific order of operations.

## Order of Operations
The order from highest to lowest priority is: "not", then "and", then "or". Expressions inside parentheses are evaluated first.

## Examples from Source
- "True and False and not True and True" evaluates to False after step-by-step simplification.
- "not not ( not ( False ) )" evaluates to True.
