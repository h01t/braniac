# Oracle v. Google Lawsuit

**Summary**: A decade-long copyright and patent dispute initiated in 2010, where Oracle alleged Google's use of Java APIs in the Android operating system constituted infringement, culminating in a 2021 U.S. Supreme Court ruling favoring Google.
**Source Context**: https://grokipedia.com/page/Google

---

The legal battle between [[entities/oracle.md]] and [[entities/google.md]] centered on Google's use of 37 packages of Java application programming interfaces (APIs) in its Android mobile operating system.

**Oracle's Claims**
Oracle, which acquired Java's original developer Sun Microsystems in 2010, sued Google that same year. It alleged that Google's copying of the APIs constituted copyright and patent infringement, seeking damages of up to $9 billion.

**Legal Proceedings and Supreme Court Decision**
The case went through multiple trials and appeals. In 2021, the U.S. Supreme Court ruled 6-2 in *Google LLC v. Oracle America, Inc.* that Google's use of the Java API packages was protected as [[concepts/fair-use.md]] under copyright law.

The Court's opinion, written by Justice Stephen Breyer, concluded that Google's copying was "transformative," as it took only what was needed to allow programmers to create new applications for the Android platform. The Court found this served a fundamentally different purpose than Oracle's original Java and did not harm Oracle's market.

**Impact**
The decision was a significant victory for Google and the software industry, affirming legal protections for [[concepts/software-interoperability.md]] and the reimplementation of APIs, which is crucial for platform development and competition.
