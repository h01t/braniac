# Training Infrastructure

**Summary**: The hardware and software systems used to train large AI models efficiently, including parallelism strategies, memory optimization, and distributed computing.

## Key Components
- **Pipeline Parallelism**: Splitting layers across GPUs.
- **Data Parallelism**: Replicating model across GPUs with different data.
- **Tensor Parallelism**: Splitting tensor operations.
