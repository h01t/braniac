# Natural Language Generation (NLG)

**Summary**: A category of evaluation tasks that assess a language model's ability to produce fluent, coherent, and contextually appropriate text based on a given input.
**Source Context**: Comprehensive Overview of LLMs.pdf (Section 5.2)

---

Natural Language Generation (NLG) focuses on the creative and productive capacities of [[concepts/large-language-models.md]]. The goal is to generate text that is not only grammatically correct but also contextually relevant and coherent. Tasks often overlap with [[concepts/natural-language-understanding-nlu.md]].

## Common NLG Tasks
*   **Summarization**: Condensing a long document into a shorter summary.
*   **Machine Translation (MT)**: Translating text from one language to another.
*   **Dialogue Generation**: Producing conversational responses, a core capability of models like [[entities/lamda.md]].
*   **Code Generation**: Writing code from a natural language description, as done by models like [[entities/alphacode.md]] and [[entities/starcoder.md]].
*   **Story/Text Completion**: Continuing a given text prompt.

Evaluation of NLG is often more subjective than NLU and may involve human evaluation or automated metrics like BLEU (for translation) or ROUGE (for summarization).
