# Retrieval-Augmented Generation (RAG)

**Summary**: A technique that enhances LLMs by retrieving relevant documents from an external knowledge base and using them to generate more accurate responses.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf

---

## Use in Agents

RAG is a key method for implementing [[concepts/memory-system.md]] in LLM agents, providing long-term memory and access to up-to-date or domain-specific information.

## Benefits

RAG can reduce hallucinations and improve the factual accuracy of agent responses.
