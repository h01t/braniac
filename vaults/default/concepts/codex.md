# Codex

**Summary**: An AI system developed by OpenAI that translates natural language into code, powering GitHub Copilot.
**Source Context**: https://grokipedia.com/page/OpenAI

---

**Codex** is an AI model developed by [[entities/openai.md]] that specializes in understanding and generating computer code. It is a descendant of [[concepts/gpt-3.md]] and was fine-tuned on a large corpus of public code (source: https://grokipedia.com/page/OpenAI).

Codex is the engine behind [[concepts/github-copilot.md]], an AI pair programmer launched in collaboration with Microsoft's GitHub in 2021. This partnership exemplified the applied scaling of OpenAI's technology within [[entities/microsoft.md]]'s ecosystem (source: https://grokipedia.com/page/OpenAI).
