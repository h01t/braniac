# Table of Contents

## Core Concepts
- [autonomous-llm-agents](concepts/autonomous-llm-agents.md): AI agents that leverage large language models for independent task execution.
- [perception-system](concepts/perception-system.md): System responsible for processing multimodal inputs like text, vision, and structured data.
- [reasoning-system](concepts/reasoning-system.md): Component that enables logical thinking, planning, and decision-making in agents.
- [memory-system](concepts/memory-system.md): Mechanism for storing and retrieving past experiences and knowledge.
- [execution-system](concepts/execution-system.md): Module that carries out actions based on reasoning and perception.
