# Tool-Augmented LLMs

**Summary**: Language models that can call external tools (APIs, calculators, search engines) to extend their capabilities beyond text generation.

## Key Aspects
- **Tool Calling**: Model decides when to call a tool.
- **Tool Descriptions**: Tools are described in the prompt or via schema.
- **Execution**: Results are fed back into the model.
