# Tool-Augmented LLMs

**Summary**: LLMs that leverage their reasoning abilities to interact with external tools (e.g., calculators, APIs, search engines) by planning, selecting tools, and executing actions to complete complex tasks.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

Tool-augmented Large Language Models extend the capabilities of LLMs beyond text generation, enabling them to act as controllers that use software tools and APIs. A generic pipeline involves the LLM reasoning about a task, generating a plan, selecting appropriate tools, executing them, and processing the results, often in an iterative loop until the task is complete.

## Zero-Shot Tool Augmentation
LLMs can often use tools without specific training, thanks to in-context learning. Methods include:
*   **Automatic Reasoning and Tool-use (ART)**: Builds a library of task demonstrations involving reasoning and tool calls, retrieves similar examples, and provides them as context to the LLM.
*   **Tool Documentation**: Some approaches show that providing tool documentation alone can be sufficient for LLMs to learn tool use without demonstrations.
*   **Other Systems**: RestGPT integrates LLMs with RESTful APIs via planning and API selection steps. ToolkenGPT represents tools as special tokens that, when generated, trigger a tool call and pause text generation until the tool's output is received (Source: Comprehensive Overview of LLMs.pdf).

## Training with Tool Augmentation
Training can enhance planning and reliability. Examples include:
*   **Gorilla**: Instruction-tunes LLaMA models using data generated by GPT-4 based on retrieved API documentation.
*   **Tool Augmented Language Model (TALM)**: Fine-tunes T5 for tool use via a self-play approach, where successful tool manipulations are added back to the training set.
*   **ToolLLM**: Creates an instruction-tuning dataset from a large collection of APIs, using a depth-first search-based decision tree (DFSDT) to generate high-quality, diverse reasoning paths (Source: Comprehensive Overview of LLMs.pdf).

## Multimodal Tool Augmentation
The compositional reasoning of LLMs allows them to manipulate tools across different modalities (text, images, etc.). Systems may use multimodal LLMs or single-modality LLMs that generate plans for using various modality-specific tools to solve multimodal queries. The typical execution sequence is: Plan → Tool Selection → Execute → Inspect → Generate (Source: Comprehensive Overview of LLMs.pdf).
