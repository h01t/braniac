# Large Language Model (LLM)

**Summary**: A neural network model trained on vast text corpora to understand and generate human language.

## Architecture
Most modern LLMs are based on the [[concepts/transformer-architecture.md]] and use attention mechanisms.

## Applications
Chatbots, code generation, translation, summarization, and more.
