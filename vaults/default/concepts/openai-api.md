# OpenAI API

**Summary**: The OpenAI API is a platform that provides developers with programmatic access to OpenAI's models, including the GPT series, DALL-E, and embeddings, enabling the integration of AI capabilities into third-party applications.
**Source Context**: OpenAI API documentation (https://platform.openai.com/docs/), pricing page (https://openai.com/api/pricing/), and quickstart guide.

---

## Core Offerings
The API offers access to a range of models, most notably the [[concepts/gpt-series.md]] for text generation and chat, the [[concepts/dall-e.md]] models for image generation, and embedding models for search and classification. It also provides fine-tuning capabilities for customizing models on proprietary data.

## Platform Features
Key features include the Assistants API for building stateful conversational agents, a File Search tool for retrieval-augmented generation (RAG), and a Realtime API for low-latency interactions. The platform also includes tools for [[concepts/ai-agents.md]] development, such as the AgentKit SDK (Source: OpenAI announcements).

## Pricing and Access
The API uses a pay-per-token consumption model, with pricing tiers varying by model capability and context window size. Access is managed through API keys and a developer dashboard. Enterprise customers can negotiate custom contracts and benefit from data privacy assurances, such as promises that data is not used for model training by default (Source: OpenAI pricing and data control pages).

## Strategic Importance
The API is a major revenue stream for [[entities/openai.md]] and a key channel for its platform strategy, enabling a vast ecosystem of third-party applications. It competes with similar offerings from other AI companies and cloud providers, including [[entities/microsoft.md]]'s Azure OpenAI Service.
