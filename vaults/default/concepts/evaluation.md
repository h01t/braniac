# Evaluation of Large Language Models
Evaluation assesses LLM performance across various domains. For [[entities/deepseek_llm.md]], evaluations include:

**Public Benchmarks:**
- Tests in code, mathematics, and reasoning.
- DeepSeek LLM 67B surpasses LLaMA-2 70B in these benchmarks.

**Open-Ended Evaluations:**
- Chinese and English assessments where DeepSeek 67B Chat outperforms GPT-3.5.

**Safety Evaluation:**
- Ensures the model provides harmless responses in practice.

**Held-Out Evaluation:**
- Additional testing to validate model robustness.

Results demonstrate superior performance, especially after alignment via [[concepts/alignment.md]]. For model specifics, see [[entities/deepseek_llm.md]].
