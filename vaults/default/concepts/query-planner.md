# Query Planner

**Summary**: The component in the VMAO framework that decomposes a complex user query into a directed acyclic graph of sub-questions, each assigned to an appropriate agent type.

## Rules
- RAG First
- Maximize Parallelism
- Minimize Dependencies
- Be Specific
