# Reinforcement Learning (RL)
A machine learning paradigm where an agent learns to make decisions by taking actions in an environment to maximize cumulative reward. In the context of language model training, RL is used to improve model outputs based on reward signals.

In the development of [[entities/DeepSeek-R1-Zero.md]] and [[entities/DeepSeek-R1.md]], RL drives the [[concepts/self-evolution.md]] of reasoning and is applied in stages (e.g., reasoning-oriented RL, RL for alignment) with rewards for task accuracy, language consistency, helpfulness, and harmlessness.
