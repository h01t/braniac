# Task Decomposition

**Summary**: The process of breaking a complex task into smaller, manageable subtasks that can be solved individually.

## Techniques
- **Hierarchical Decomposition**: Top-down breakdown.
- **DAG Decomposition**: With dependencies ([[concepts/dag-query-decomposition.md]]).
