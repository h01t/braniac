# Agent Harness

**Summary**: An agent harness is a system that combines complex skills, memory, and external modules to enhance an AI agent's adaptability in various environments.
**Source Context**: https://www.minimax.io/news/minimax-m27-en

---

## Description

Agent harnesses utilize skills, memory, and other components to improve an agent's performance in heterogeneous working environments. In MiniMax, agents use harnesses to collaborate with research teams and handle complex tasks.

## Role in Self-Evolution

The blog post describes how M2.7 builds a research agent harness that supports data pipelines, training environments, and persistent memory, enabling researchers to drive model iterations.

## Components

Key components include short-term memory, self-feedback, and self-optimization modules, as used in experiments on [[concepts/benchmarking.md|MLE Bench Lite]].
