# Structured Data Perception

**Summary**: Structured Data Perception refers to the use of structured data formats (like JSON, XML, A11y trees, HTML) to help LLM agents understand their environment, particularly in GUI or database contexts.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf

---

Structured Data Perception involves using data in structured formats to provide precise semantic understanding of the environment. This includes formats such as JSON, XML, database records, and accessibility trees (A11y trees). The data is typically obtained through parsers, database query tools, or accessibility frameworks.

Examples of structured data perception include the use of [[concepts/accessibility-tree-perception.md]] and [[concepts/html-utilization-perception.md]]. These methods are efficient for structured environments like GUIs or databases, but they are limited to environments where such structured data is available and require predefined schemas or parsing logic.

Table 1 in the source document summarizes Structured Data Perception as having strengths in precise semantic understanding and efficiency, but limitations in requiring structured data and parsing logic.
