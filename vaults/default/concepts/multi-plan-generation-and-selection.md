# Multi-Plan Generation and Selection

**Summary**: A robust reasoning approach where an LLM agent generates multiple alternative plans for a task and then uses search algorithms or consensus methods to select the optimal one.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf

---

Due to task complexity and LLM uncertainty, a single generated plan may be suboptimal. Multi-plan generation and selection addresses this by having the [[concepts/reasoning-system|reasoning system]] explore a diverse set of candidate solutions before committing to one [Source: Fundamentals of Building Autonomous LLM Agents.pdf].

## Generation Strategies
Multiple plans are generated by leveraging the uncertainty in the LLM's decoding process:
*   **Self-Consistent Chain-of-Thought (CoT-SC)**: Generates various reasoning paths and corresponding answers, then selects the most frequent answer as the final output [Source: Fundamentals of Building Autonomous LLM Agents.pdf].
*   **Tree-of-Thought (ToT)**: Uses a tree-like reasoning structure where each node is an intermediate "thought." The LLM is queried to evaluate and select steps, enabling a search over reasoning paths [Source: Fundamentals of Building Autonomous LLM Agents.pdf].
*   **Graph of Thoughts (GoT)**: Extends ToT to graph structures, supporting arbitrary thought aggregation and transformations for more powerful prompting [Source: Fundamentals of Building Autonomous LLM Agents.pdf].
*   **LLM-MCTS and RAP**: Leverage the LLM as a heuristic policy for Monte Carlo Tree Search (MCTS). **RAP** specifically builds a world model to simulate potential outcomes of different plans using MCTS [Source: Fundamentals of Building Autonomous LLM Agents.pdf].

## Selection Strategies
Once candidates are generated, selection algorithms are employed:
*   **Self-Consistency**: Uses a simple majority vote.
*   **Tree Search Algorithms**: Methods like ToT use Breadth-First Search (BFS) or Depth-First Search (DFS) for expansion and selection [Source: Fundamentals of Building Autonomous LLM Agents.pdf].
*   **Monte Carlo Tree Search (MCTS)**: Used by LLM-MCTS and RAP to navigate the plan search space [Source: Fundamentals of Building Autonomous LLM Agents.pdf].

## Trade-offs
This approach allows for broader solution exploration but comes with increased computational demands. Furthermore, reliance on LLMs for plan evaluation introduces challenges due to their performance in ranking tasks and inherent stochasticity, which can affect the consistency of chosen plans [Source: Fundamentals of Building Autonomous LLM Agents.pdf].
