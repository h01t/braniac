# Agent Teams
A multi-agent collaboration paradigm where multiple AI agents, each with distinct roles, work together to complete complex tasks. This requires native model capabilities beyond simple prompting, such as role anchoring, adversarial reasoning, protocol adherence, and behavioral differentiation.

## Core Requirements
*   **Role Identity:** Agents must stably maintain their assigned personas.
*   **Adversarial Reasoning:** Agents should proactively challenge teammates' logic and ethical blind spots.
*   **State Machine Navigation:** Agents must make autonomous decisions within complex workflows.

## Application
Used internally at MiniMax for product prototype development, involving a minimal organizational structure of collaborating agents. This is a sophisticated demonstration of [[concepts/agentic-capabilities.md]].
