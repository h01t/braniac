# Learning Classification
A theory in educational psychology, as per Chinese psychologist Feng Zhongliang, categorizing learning into types such as knowledge learning, skill learning, behavior norm learning, and attitude learning.

## Example from Source
Cultivating morality through behavior norm learning, as indicated in a BBH question.
