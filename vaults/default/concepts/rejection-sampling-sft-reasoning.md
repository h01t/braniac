# Rejection Sampling and Supervised Fine-Tuning for Reasoning Models

**Summary**: A stage in the training pipeline where high-quality reasoning and general-purpose data are collected via rejection sampling from an RL checkpoint and used for supervised fine-tuning.
**Source Context**: DeepSeek_R1.pdf

---

## Data Curation Process
After the [[concepts/reasoning-oriented-reinforcement-learning.md]] phase converges, the resulting checkpoint is used to generate data for supervised fine-tuning (SFT). This involves two types of data (Source: DeepSeek_R1.pdf).

**Reasoning Data**: Prompts are curated, and multiple responses are generated via rejection sampling. Only correct responses are retained. The data is filtered for readability, removing chains of thought with mixed languages or poor formatting. Some data uses a generative reward model (DeepSeek-V3) for judgment instead of rule-based rewards. About 600k reasoning samples are collected (Source: DeepSeek_R1.pdf).

**Non-Reasoning Data**: This includes writing, factual QA, and translation tasks. The pipeline reuses parts of the [[entities/deepseek-v3-base.md]] SFT dataset. For some tasks, a chain of thought is generated by prompting DeepSeek-V3 before the answer. About 200k non-reasoning samples are collected (Source: DeepSeek_R1.pdf).

The combined ~800k sample dataset is used to fine-tune the base model for two epochs, enhancing both reasoning and general capabilities (Source: DeepSeek_R1.pdf).
