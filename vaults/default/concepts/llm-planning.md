# LLM Planning

**Summary**: The ability of language models to break down tasks into sequences of actions, often using techniques like Chain-of-Thought, Tree-of-Thoughts, or DPPM.

## Key Techniques
- **Chain-of-Thought**: Step-by-step reasoning.
- **Tree-of-Thoughts**: Explore multiple reasoning paths.
- **ReAct**: Interleaved reasoning and acting.
