# Accessibility Tree (A11y Tree) in Perception

**Summary**: The Accessibility Tree (A11y Tree) is a hierarchical representation of GUI components used by LLM agents to understand the structure and semantics of user interfaces.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf (citing [56]: OSCAR)

---

The Accessibility Tree, also known as A11y Tree, is generated by the Windows API and represents GUI components with descriptive labels. It is used in systems like OSCAR [56] to facilitate semantic grounding for LLM agents.

In the context of LLM agent perception, the A11y Tree provides structured data that can be combined with visual information (e.g., from screenshots) to build a rich understanding of the GUI environment.

The use of Accessibility Tree is part of the broader category of [[concepts/structured-data-perception.md]].
