# Agentic Capabilities
The set of abilities that enable an AI model to act as an autonomous agent, including planning, tool use, skill invocation, memory, and multi-step reasoning to achieve complex goals.

## Key Aspects
*   **Complex Task Completion:** Ability to handle elaborate, multi-stage productivity tasks.
*   **Environment Interaction:** Capability to work within and understand complex software or workspace environments.
*   **Skill Adherence:** Reliability in correctly invoking and following a large set of predefined complex skills.
*   **Multi-Agent Collaboration:** Foundational ability for participation in [[concepts/agent-teams.md]].

## Demonstrated By
These capabilities are a hallmark of [[entities/MiniMax M2.7.md]], enabling its use in [[concepts/self-evolution.md]], professional software engineering, and office work automation.
