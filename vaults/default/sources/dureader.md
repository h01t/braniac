# DuReader: A Chinese Machine Reading Comprehension Dataset from Real-world Applications

**Summary**: A Chinese MRC dataset constructed from real user queries and web documents, focusing on real-world, open-domain question answering with diverse question types.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

## Overview
DuReader is a large-scale Chinese [[concepts/machine-reading-comprehension.md]] dataset sourced from Baidu Search and Baidu Zhidao. Unlike datasets derived from Wikipedia, DuReader's questions are real, user-generated queries, and the documents are from web pages, making it a benchmark for real-world [[concepts/question-answering.md]] applications. It includes yes/no, entity, and description questions, requiring more than simple span extraction.

It is cited as a primary benchmark for evaluating Chinese language understanding in LLMs.

## Key Details
*   **Authors**: He, W., Liu, K., Liu, J., Lyu, Y., Zhao, S., et al.
*   **Venue**: arXiv preprint arXiv:1711.05073.
*   **Year**: 2017.
*   **Characteristics**: Real queries, web documents, diverse answer types.
