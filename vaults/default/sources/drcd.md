# DRCD: A Chinese Machine Reading Comprehension Dataset

**Summary**: A large-scale, domain-agnostic Chinese machine reading comprehension dataset built from traditional Chinese Wikipedia articles.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

## Overview
DRCD is a Chinese-language dataset designed for the [[concepts/machine-reading-comprehension.md]] (MRC) task. It was created to provide a high-quality benchmark for evaluating Chinese NLP models, similar to English datasets like SQuAD. The dataset is built from Wikipedia articles and features span-extraction questions, where the answer is a contiguous segment of text from a given passage.

It is part of a suite of Chinese MRC datasets used to assess the multilingual capabilities of [[concepts/large-language-models.md]].

## Key Details
*   **Authors**: Shao, C. C., Liu, T., Lai, Y., Tseng, Y., Tsai, S.
*   **Venue**: arXiv preprint arXiv:1806.00920.
*   **Year**: 2018.
*   **Language**: Traditional Chinese.
*   **Task**: Span-extraction reading comprehension.

## Related Concepts
This dataset is a key [[concepts/benchmarks.md]] for Chinese NLP. It exists alongside other Chinese MRC datasets like [[sources/dureader.md]] and [[sources/dureaderrobust.md]] to test model robustness and comprehension.
