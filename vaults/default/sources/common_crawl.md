# Common Crawl
Common Crawl is a web corpus used in data collection for pre-training large language models.

**Usage in DeepSeek LLM:**
- Employed for gathering pre-training data.
- Deduplication was performed across 91 dumps, increasing efficiency by removing up to 89.8% duplicate documents.

This data processing is part of [[concepts/pre_training.md]] for models like [[entities/deepseek_llm.md]].
