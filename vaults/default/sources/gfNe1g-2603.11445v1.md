# gfNe1g-2603.11445v1.pdf — Verified Multi-Agent Orchestration

**Summary**: A conference paper published at ICLR 2026 Workshop on MALGAI, introducing the VMAO framework for complex query resolution using a Plan-Execute-Verify-Replan loop.
**Source Context**: /Users/grmim/Downloads/gfNe1g-2603.11445v1.pdf (local file).

---

The paper was authored by Xing Zhang, Yanwei Cui, Guanghui Wang, Qucy Wei Qiu, Ziyuan Li, Fangwei Han, Yajing Huang, Hengzhi Qiu, Bin Zhu, and Peiyang He, affiliated with AWS Generative AI Innovation Center and HSBC. arXiv identifier: 2603.11445v1.

Key contributions:
- DAG-based query decomposition and execution ([[concepts/dag-query-decomposition.md]]).
- Verification-driven adaptive replanning ([[concepts/verification-driven-replanning.md]]).
- Configurable stop conditions ([[concepts/stop-conditions.md]]).
- Agent taxonomy with 42 tools ([[concepts/agent-taxonomy.md]]).

Experiments on 25 market research queries showed substantial improvements in completeness and source quality. The implementation uses LangGraph, Strands Agent framework, AWS Bedrock, and Claude models.
