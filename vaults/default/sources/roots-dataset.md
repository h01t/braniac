# ROOTs Dataset

**Summary**: A large, multilingual corpus of 1.61TB compiled from 498 datasets on Hugging Face, covering 46 natural and 13 programming languages for pre-training language models.
**Source Context**: Comprehensive Overview of LLMs.pdf.

---

## Description
The ROOTs dataset is a massive, multilingual corpus designed for pre-training large language models. It aggregates content from 498 constituent sub-datasets available on the Hugging Face platform.

## Key Attributes
*   **Size**: 1.61 Terabytes (TB).
*   **Source**: 498 Hugging Face datasets.
*   **Languages**: 46 natural languages and 13 programming languages.
*   **Creation Method**: Automated compilation.

## Usage
The dataset was notably used to pre-train the [[entities/bloom-model.md]] model. Its diverse linguistic and programming content aims to support the development of models with broad cross-lingual and code understanding capabilities.
