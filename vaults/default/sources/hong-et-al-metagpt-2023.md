# Hong et al., MetaGPT (2023)

**Summary**: Proposes MetaGPT, a meta programming framework for multi-agent collaboration that assigns different roles (e.g., product manager, architect, engineer) to LLM-based agents, standardizing operating procedures and embedding human workflows to enhance collaborative task completion.
**Source Context**: Hong, S., Zheng, X., Chen, J., et al. *MetaGPT: Meta programming for multi-agent collaborative framework*, arXiv:2308.00352 (2023). From Comprehensive Overview of LLMs.pdf (citation 229)

---

MetaGPT advances the field of [[concepts/tool-use-agents.md]] by structuring multi-agent collaboration. It encodes Standardized Operating Procedures (SOPs) into prompts, guiding agents with specialized roles to work together on complex tasks like software development. By generating structured outputs like requirements documents, design diagrams, and code, MetaGPT aims to improve coherence and success rates in multi-step projects.

This work illustrates how LLM agents can move beyond single-turn tool use to coordinated, long-horizon problem-solving.
