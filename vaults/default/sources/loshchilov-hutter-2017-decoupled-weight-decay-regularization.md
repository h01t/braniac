# Decoupled Weight Decay Regularization
**Authors:** Loshchilov, I. and Hutter, F.
**Venue:** arXiv preprint arXiv:1711.05101
**Year:** 2017

## Summary
Proposes decoupled weight decay regularization, a modification of AdamW optimizer that decouples weight decay from the gradient update.
