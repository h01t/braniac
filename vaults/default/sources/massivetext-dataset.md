# MassiveText Dataset

**Summary**: A 10.5TB English-dominant pre-training corpus composed of web pages, books, news, Wikipedia, GitHub, and C4 data.
**Source Context**: Comprehensive Overview of LLMs.pdf.

---

## Description
MassiveText is a very large-scale dataset used for pre-training language models. It is composed of several constituent data sources, with an overwhelming majority of its content in the English language.

## Key Attributes
*   **Size**: 10.5 Terabytes (TB).
*   **Sources**: MassiveWeb, Books, News, Wikipedia, GitHub, and C4 (Colossal Clean Crawled Corpus).
*   **Languages**: Approximately 99% English.
*   **Creation Method**: Automated.

## Usage
This dataset was used in the training of models like [[entities/gopher-model.md]] and [[entities/chinchilla-model.md]]. Its scale and focus on high-quality web text make it a foundational resource for building capable English language models.
