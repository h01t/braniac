# QwQ-32B-Preview

**Summary**: A 32-billion parameter reasoning model developed by Qwen, used as a performance benchmark in the DeepSeek-R1 experiments.
**Source Context**: DeepSeek_R1.pdf (Table 5, Table 6, References).

---

## Benchmark Role
In the DeepSeek-R1 paper, [[entities/qwq-32b-preview.md]] serves as a key benchmark for comparison. It is a reasoning-optimized model against which the performance of the distilled and RL-trained DeepSeek models are measured.

## Performance Context
As shown in Tables 5 and 6, QwQ-32B-Preview's scores (e.g., 50.0% on AIME 2024, 60.0% on MATH-500) are surpassed by the larger DeepSeek-R1 distilled models (like the 32B and 70B variants). Notably, the RL-trained [[entities/deepseek-r1-zero-qwen-32b.md]] achieved performance described as "on par" with QwQ-32B-Preview.
