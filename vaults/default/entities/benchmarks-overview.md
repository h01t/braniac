# Benchmarks Overview
- **List of Benchmarks Mentioned in MiniMax M2.7 Announcement**:
  - **SWE-Pro**: Measures software engineering proficiency across multiple programming languages. M2.7 scored 56.22%.
  - **VIBE-Pro**: Evaluates end-to-end full project delivery. M2.7 scored 55.6%.
  - **Terminal Bench 2**: Tests deep understanding of complex engineering systems. M2.7 scored 57.0%.
  - **NL2Repo**: Requires high system-level comprehension for natural language to repository tasks.
  - **GDPval-AA**: Assesses domain expertise and task delivery in professional work. M2.7 has ELO 1495.
  - **Toolathon**: Evaluates tool invocation accuracy. M2.7 achieved 46.3%.
  - **MM Claw**: Covers real-world agent tasks in work and life. M2.7 accuracy 62.7%.
  - **MLE Bench Lite**: Machine learning competitions used to test self-evolution capabilities. M2.7 achieved average medal rate 66.6%.
- **Comparative Models**: Compared to models like Opus, GPT, Gemini, and Sonnet in performance.
