# DeepSeek-R1-Distill-Qwen-7B

**Summary**: A 7-billion parameter distilled model that outperforms non-reasoning models like GPT-4o-0513 across reasoning benchmarks.
**Source Context**: DeepSeek_R1.pdf (Table 5, Section 3.2).

---

## Model Description
[[entities/deepseek-r1-distill-qwen-7b.md]] (also abbreviated as DeepSeek-R1-7B in the text) is one of the series of models created by distilling the [[entities/deepseek-r1.md]] teacher model. It is highlighted as an example of an "efficient" model that gains strong reasoning through distillation.

## Reported Performance
As shown in Table 5, the model achieves strong scores across several reasoning benchmarks, including 55.5% on [[entities/aime-2024.md]] and 92.8% on [[entities/math-500.md]]. The text explicitly states that this model "outperform[s] non-reasoning models like GPT-4o-0513 across the board."
