# VideoChat-Text

**Summary**: A video understanding model that incorporates the Whisper speech recognition model to generate video captions for an LLM.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

VideoChat-Text is an example of a [[concepts/fine-tuning-for-mllms.md]] model that uses an expert model. It incorporates **[[entities/whisper.md]]**, a speech recognition expert model, to generate captions for given videos. These captions are then provided to an LLM for understanding [Source: Comprehensive Overview of LLMs.pdf].
