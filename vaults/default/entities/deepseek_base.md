# DeepSeek Base Models
The pre-trained, non-chat tuned versions of the DeepSeek LLM.

**Key Details:**
*   **Sizes:** 7B and 67B parameters.
*   **Pre-training:** Trained on a 2 trillion token bilingual (English & Chinese) corpus.
*   **Performance:** Show comparable English performance to [[entities/llama2.md]] and superior performance on math, code, and Chinese benchmarks.
*   **Scaling:** The 67B model shows stronger emergent improvements on tasks like [[entities/gsm8k.md]].
