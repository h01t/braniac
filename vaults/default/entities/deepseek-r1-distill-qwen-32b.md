# DeepSeek-R1-Distill-Qwen-32B

**Summary**: A 32-billion parameter model created by distilling the DeepSeek-R1 teacher model, which significantly outperformed a 32B model trained with pure reinforcement learning from scratch.
**Source Context**: DeepSeek_R1.pdf

---

## Model Overview
**DeepSeek-R1-Distill-Qwen-32B** is a distilled model from the DeepSeek-R1 family. It was created by applying [[concepts/knowledge-distillation.md]] (SFT) to a Qwen-32B base model using 800,000 samples generated by the [[entities/deepseek-r1.md]] teacher (Source: DeepSeek_R1.pdf).

## Performance
As shown in Table 5 of the paper, this model achieved strong results on reasoning [[concepts/benchmarking.md]], including 72.6% on [[benchmarks/aime-2024.md]], 83.3% on [[benchmarks/math-500.md]], and 94.3% on [[benchmarks/gpqa-diamond.md]] (Source: DeepSeek_R1.pdf).

## Critical Comparative Result
This model played a central role in the paper's analysis comparing distillation vs. reinforcement learning. Its performance was directly compared to:
*   **[[entities/qwq-32b-preview.md]]**: DeepSeek-R1-Distill-Qwen-32B surpassed it on all evaluation metrics.
*   **DeepSeek-R1-Zero-Qwen-32B**: A 32B base model (Qwen-32B-Base) trained with **over 10,000 steps of large-scale RL** from scratch. The distilled model **"performs significantly better than DeepSeek-R1-Zero-Qwen-32B across all benchmarks"** (Source: DeepSeek_R1.pdf, Table 6).

This comparison provided strong evidence that for creating capable smaller reasoning models, distilling from a powerful teacher is more effective than attempting to train the small model with large-scale RL from scratch.
