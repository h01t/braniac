# VCoder

**Summary**: A versatile vision encoder for multimodal large language models, proposed by Jain et al. (2023) to enhance visual perception.
**Source Context**: Fundamentals of Building Autonomous LLM Agents.pdf

---

## Purpose

VCoder is designed to address limitations in fundamental visual perception in MM-LLMs, such as object identification and counting, and to reduce hallucination.

## Approach

VCoder uses an adaptive architecture and integrates additional information like segmentation and depth maps to improve the MM-LLM's understanding of images.

## Relation to Agents

VCoder is an example of an external visual encoder that can enhance the [[concepts/perception-system.md]] of an agent using [[concepts/multimodal-large-language-models.md]].
