# LLaMA-Adapter

**Summary**: A parameter-efficient fine-tuning method for multimodal LLMs that uses an efficient transformer-based adapter module.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

LLaMA-Adapter is a technique for [[concepts/fine-tuning-for-mllms.md]]. It applies an efficient transformer-based adapter module for training, allowing a pre-trained LLM to be adapted to multimodal tasks in a parameter-efficient manner [Source: Comprehensive Overview of LLMs.pdf].
