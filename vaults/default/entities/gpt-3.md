# GPT-3

**Summary**: A 175B parameter autoregressive language model from OpenAI that uses sparse transformers and popularized in-context learning.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

GPT-3 is a seminal 175B parameter decoder-only LLM. It uses **sparse transformers** as part of a [[concepts/sparse-vs-dense-models.md]] architecture [Source: Comprehensive Overview of LLums.pdf]. It popularized **in-context learning** as a method for [[concepts/controllable-text-generation.md]] [Source: Comprehensive Overview of LLums.pdf]. Its learning rate schedule has been used as a reference for interpolating rates in other large models [Source: Comprehensive Overview of LLums.pdf].
