# Educational Datasets
A collection of benchmarks referenced in the PDF, used for evaluating various competencies.

## Datasets Included
- BBH, C-Eval, C3, CCPM, CMATH, CMMLU, DROP, CHID, CLUEWSC, GSM8K, HumanEval, MATH, MBPP, MMLU, NaturalQuestions, OpenBookQA, PIQA

## Descriptions
- Each dataset focuses on specific domains like education, math, language, or programming.
- Examples provided in the PDF illustrate question formats and answer types.
