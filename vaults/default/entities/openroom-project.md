# OpenRoom

**Summary**: OpenRoom is an open-source interaction system built on an agent harness, demonstrating AI interaction in a Web GUI space.

**Source Context**: https://www.minimax.io/news/minimax-m27-en

---

## Overview

OpenRoom is a demo project that uses M2.7's character consistency and conversational capabilities to create interactive entertainment experiences. It was open-sourced by MiniMax (Source: https://www.minimax.io/news/minimax-m27-en).

## Development

Most of the code for OpenRoom was written by AI, as mentioned in the blog post. The repository is available at [https://github.com/MiniMax-AI/OpenRoom](https://github.com/MiniMax-AI/OpenRoom) (Source: https://www.minimax.io/news/minimax-m27-en).
