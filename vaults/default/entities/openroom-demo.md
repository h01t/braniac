# OpenRoom Demo
- **Description**: An interactive system based on an agent harness that liberates AI interaction from text streams to a Web GUI space with real-time visual feedback and scene interactions.
- **Purpose**: To explore new ways for humans and agents to interact, emphasizing character consistency and entertainment beyond productivity.
- **Repository**: https://github.com/MiniMax-AI/OpenRoom
- **Live Demo**: https://www.openroom.ai/
