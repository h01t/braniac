# BrowseComp Benchmark

**Summary**: A benchmark for evaluating browsing agents, described as a "simple yet challenging" test used to measure the performance of agentic systems like Agent Swarm.
**Source Context**: 2602.02276v1.pdf; Reference [68]: Wei et al., "BrowseComp: A Simple Yet Challenging Benchmark for Browsing Agents," 2025.

---

## Purpose and Use
BrowseComp is used to evaluate the efficiency and accuracy of browsing agents (Source: 2602.02276v1.pdf). In the Kimi K2.5 report, it served as a testbed where the **[[concepts/agent-swarm.md]]** strategy was shown to outperform a "Discard-all" context truncation baseline (Source: 2602.02276v1.pdf).

## Citation
The benchmark is cited as reference [68] in the Kimi K2.5 technical report: Jason Wei et al., "BrowseComp: A Simple Yet Challenging Benchmark for Browsing Agents," 2025, arXiv:2504.12516 (Source: 2602.02276v1.pdf).
