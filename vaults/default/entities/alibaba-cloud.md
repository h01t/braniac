# Alibaba Cloud (Qwen Series)

**Summary**: Alibaba Cloud is a major Chinese tech company that has released dozens of Qwen series [[concepts/large-language-model.md]]s under open-source licenses, ranging from small 0.5B parameter models to large 72B+ models, with specialized variants for coding and multimodal tasks.
**Source Context**: https://intuitionlabs.ai/articles/chinese-open-source-llms-2025

---

## Model Series and Releases
Alibaba's primary open-source LLM family is the **Qwen series**. The original Qwen 2.5 family (0.5B to 72B parameters) was open-sourced in 2024 [^3]. In 2025, Alibaba introduced enhanced variants:
*   **Qwen2.5-Max**: An enhanced model which Alibaba claimed surpassed competing models like [[entities/deepseek.md]]'s V3 [^7].
*   **Qwen3-Coder**: A 32B parameter coding model touted as outperforming domestic rivals and matching OpenAI's GPT-4 on code generation tasks [^4].

## Key Features and Accessibility
Alibaba's models support multilingual and multimodal tasks (text, code, and image understanding). According to Reuters, Alibaba's Qwen Chat service allows developers to access all public Qwen models by simply selecting them in the interface [^8]. The company maintains that its Qwen LLM line is fully open-sourced, though it also develops commercial models like Wanxiang for video [^3].

## Strategic Position
Alibaba's aggressive open-source releases are part of a broader competitive push in the [[concepts/chinese-open-source-llm-landscape-2025.md]], often benchmarked against other leading Chinese and U.S. models [^4][^7].
