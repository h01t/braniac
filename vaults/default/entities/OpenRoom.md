# OpenRoom
An interactive AI agent demo project open-sourced by [[entities/MiniMax.md]]. It is built on an agent harness and liberates AI interaction from text into an interactive Web GUI space.

## Features
*   Character-driven interactions with real-time visual feedback.
*   Conversation drives scene interactions.
*   Showcases the character consistency and emotional intelligence of [[entities/MiniMax M2.7.md]].
