# DeepSeek-R1-Zero
A variant of the DeepSeek reasoning model representing a "pure" reinforcement learning approach.

**Development Approach:**
*   Trained using **[[concepts/reinforcement-learning-rl.md]]** **without relying on any cold-start data**.
*   Contrasts with [[entities/DeepSeek-R1.md]], which used cold-start data alongside RL.

**Performance:**
*   Achieved strong performance across various reasoning tasks.
*   Demonstrated the viability of a pure RL pathway for enhancing model reasoning.
