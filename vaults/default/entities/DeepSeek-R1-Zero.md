# DeepSeek-R1-Zero
A reasoning model developed through pure [[concepts/self-evolution.md]] via [[concepts/reinforcement_learning.md]] directly from the base model (DeepSeek-V3-Base). It autonomously learns to solve complex reasoning tasks by leveraging extended test-time computation (generating hundreds to thousands of reasoning tokens).

**Key Characteristics:**
*   Demonstrates emergent sophisticated behaviors like reflection.
*   Exhibits an [[concepts/aha_moment.md]] during training.
*   Faces drawbacks like poor readability and language mixing.
*   Its development inspired the [[concepts/reinforcement_learning_cold_start.md]] approach used for [[entities/DeepSeek-R1.md]].
