# PaLM

**Summary**: A large language model from Google that uses parallel attention and multi-query attention architectures.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

PaLM (Pathways Language Model) is a decoder-only LLM. It utilizes the [[concepts/parallel-attention.md]] architecture and [[concepts/multi-query-attention.md]] [Source: Comprehensive Overview of LLums.pdf]. It is an example of a model where increasing the decoder-only size may reduce the performance gap with encoder-decoder architectures [Source: Comprehensive Overview of LLMs.pdf].
