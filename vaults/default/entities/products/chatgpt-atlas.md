# ChatGPT Atlas

**Summary**: An AI-integrated web browser built by OpenAI on Chromium, designed to enhance web navigation with embedded ChatGPT capabilities like instant answers and proactive task assistance.
**Source Context**: https://grokipedia.com/page/OpenAI

---

## Overview and Launch

ChatGPT Atlas is an AI-integrated web browser built on the [[entities/technology/chromium.md]] engine. It embeds [[entities/products/chatgpt.md]] capabilities directly into the browsing experience to provide instant answers, content summaries, and proactive task assistance [210].

Announced on October 21, 2025, Atlas positions OpenAI as a direct competitor to [[entities/technology/google-chrome.md]] by leveraging AI to reinterpret fundamental web navigation tasks [211].

## Availability and Capabilities

Initial global availability began on macOS on October 21, 2025, with support for Windows, iOS, and Android slated for subsequent rollout [211].

The browser is designed to work alongside OpenAI's advancing [[concepts/agent-frameworks.md]]. For example, it can facilitate AI agents performing tasks like online shopping (e.g., on Instacart) by understanding user requests and interacting with web pages [Source Context].
