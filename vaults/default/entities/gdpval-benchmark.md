# GDPVal Benchmark

**Summary**: An evaluation benchmark cited in the Kimi K2.5 report, with scores reflecting official leaderboard metrics as of January 28, 2026.
**Source Context**: Kimi K2.5 Technical Report (2602.02276v1.pdf)

---

GDPVal (also referred to as GDPVal-AA) is an evaluation benchmark by Artificial Analysis. The Kimi K2.5 report cites GDPVal-AA evaluation, and the scores reported in the model's results table reflect the official leaderboard metrics as of January 28, 2026. This benchmark is part of the comprehensive [[concepts/evaluation-protocols-for-multimodal-models.md]] used to assess [[entities/kimi-k2-5-model.md]] against other leading models.
