# T0

**Summary**: An instruction-tuned language model that demonstrated the effectiveness of multi-task prompting for zero-shot generalization.
**Source Context**: Comprehensive Overview of LLMs.pdf, Section 3.2.1 and Table 2.

---

**T0** is a model fine-tuned using a diverse set of prompts applied to existing NLP datasets. Its development provided key insights into instruction tuning.

## Key Findings & Contributions
*   **Multi-task Prompting**: T0 showed that training on multiple tasks via prompts enables strong zero-shot generalization to held-out tasks, outperforming non-instructed baselines.
*   **Prompt Efficiency**: It demonstrated that even a **single prompt per dataset task** can be enough to significantly improve model performance.
*   **Generalization**: The model's success helped establish that instruction tuning is a powerful method for teaching models to follow instructions and generalize.

## Technique
T0 was created by converting numerous existing datasets into a unified prompt format, creating a large and diverse instruction-tuning dataset without manually writing all instructions from scratch.
