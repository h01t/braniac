# PointClip V2

**Summary**: A visual reasoning system that uses an LLM to generate 3D-specific prompts, which are combined with visual features for 3D recognition.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

PointClip V2 is an example of a system for [[concepts/visual-reasoning-with-llms.md]]. It applies an LLM to generate 3D-specific prompts. These textual prompts are encoded into features and then combined with visual features to perform 3D recognition tasks [Source: Comprehensive Overview of LLMs.pdf].
