# Grok-1

**Summary**: A 314-billion parameter mixture-of-experts (MoE) language model developed by xAI, with 8 experts and 2 activated per token.
**Source Context**: Comprehensive Overview of LLMs.pdf.

---

## Model Description
Grok-1 is a large language model from xAI. It is a **[[concepts/mixture-of-experts.md]] model** with a total of **314 billion parameters**. The MoE layer consists of **8 experts**, and for each input token, the routing mechanism selects **2 experts to be activated**. The model is part of the Grok family, which also includes the multi-modal Grok-1.5 with a larger context length (Source: Comprehensive Overview of LLMs.pdf).
