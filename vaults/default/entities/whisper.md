# Whisper

**Summary**: An automatic speech recognition (ASR) model developed by OpenAI, used as an expert component in some multimodal LLM pipelines.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

Whisper is a speech recognition model. In the context of [[concepts/multimodal-llms.md]], it is used as an expert model within systems like **[[entities/videochat-text.md]]** to convert the audio modality into language (captions) that can be processed by a following LLM [Source: Comprehensive Overview of LLMs.pdf].
