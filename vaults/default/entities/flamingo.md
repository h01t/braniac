# Flamingo

**Summary**: A multimodal LLM that uses gated cross-attention to fuse features from frozen pre-trained visual and language models.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

Flamingo is an example of a [[concepts/pre-training-for-mllms.md]] model. It applies gated cross-attention to fuse the vision and language modalities, which are sourced from a pre-trained and frozen visual encoder and a frozen LLM, respectively [Source: Comprehensive Overview of LLMs.pdf].
