# Datasets
Datasets mentioned in training and evaluation:
- **OpenWebText2**: High-quality dataset used in scaling laws studies.
- **In-house Data**: Iteratively refined, with current data higher quality than early versions.
- **GSM8K**: Mathematical problem dataset for evaluation.
- **HumanEval**: Coding exercise dataset for evaluation.
- **Instruction Data**: 1.5 million instances in English and Chinese for alignment.
Data quality impacts [[concepts/scaling_laws.md]].
