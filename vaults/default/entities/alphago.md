# AlphaGo

**Summary**: The pioneering AI system developed by DeepMind that mastered the game of Go, cited as inspiration for exploring Monte Carlo Tree Search in language models.
**Source Context**: DeepSeek_R1.pdf (Section 4.2, References: Silver et al., 2017b).

---

## Mentioned Context
[[entities/alphago.md]] is referenced as the inspiration for the research team's exploration of [[concepts/monte-carlo-tree-search-mcts.md]] to enhance language model reasoning. The paper notes that AlphaGo's core success relied on training a value model to guide search and improve iteratively—a principle they found difficult to replicate for token-based language generation.
