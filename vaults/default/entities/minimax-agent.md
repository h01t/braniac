## Description

MiniMax Agent is an AI-native application where M2.7 is available. It enables users to leverage the model's capabilities for software engineering, professional work, and entertainment (Source: https://www.minimax.io/news/minimax-m27-en).

## Availability

According to the blog post, M2.7 is fully available on MiniMax Agent at [agent.minimax.io](https://agent.minimax.io) (Source: https://www.minimax.io/news/minimax-m27-en).
