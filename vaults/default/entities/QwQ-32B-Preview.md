# QwQ-32B-Preview
A 32-billion parameter preview model from Qwen, described as reasoning about the "boundaries of the unknown."

**Context in Source:**
*   Used as a performance benchmark.
*   **DeepSeek-R1-14B** (a distilled model) surpassed QwQ-32B-Preview on all evaluation metrics.
*   The pure RL model **[[entities/DeepSeek-R1-Zero-Qwen-32B.md]]** achieved performance on par with QwQ-32B-Preview.
