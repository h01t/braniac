# GPT4Tools

**Summary**: A visual reasoning system that fine-tunes an LLM using LoRA on tool-related instructions.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

GPT4Tools is a system for [[concepts/visual-reasoning-with-llms.md]]. It employs **LoRA** (Low-Rank Adaptation) to fine-tune an LLM following tool-related instructions, enabling the model to use external tools for visual reasoning tasks [Source: Comprehensive Overview of LLMs.pdf].
