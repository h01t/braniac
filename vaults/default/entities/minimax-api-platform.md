# MiniMax API Platform

**Summary**: The MiniMax API Platform provides developers with access to AI models like M2.7 through APIs.

**Source Context**: https://www.minimax.io/news/minimax-m27-en

---

## Description

The API platform allows developers to integrate MiniMax models into their applications. M2.7 is available on this platform for coding plans and other uses (Source: https://www.minimax.io/news/minimax-m27-en).

## Access

As per the blog post, the API is accessible at [platform.minimax.io](https://platform.minimax.io) (Source: https://www.minimax.io/news/minimax-m27-en).
