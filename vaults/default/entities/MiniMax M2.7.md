# MiniMax M2.7
A large language model released by [[entities/MiniMax.md]] on March 18, 2026. It is described as the first model to be deeply involved in its own evolutionary process, exhibiting advanced [[concepts/agentic-capabilities.md]].

## Key Features & Capabilities
*   **Self-Evolution:** Capable of participating in its own development cycle (see [[concepts/self-evolution.md]]).
*   **Software Engineering:** Excels in real-world programming, including end-to-end project delivery, log analysis, bug troubleshooting, and code security. Performs strongly on benchmarks like SWE-Pro (56.22%), VIBE-Pro (55.6%), and Terminal Bench 2 (57.0%).
*   **Professional Office Work:** Enhanced expertise in Word, Excel, and PPT for complex editing and multi-round revisions. Achieved an ELO of 1495 on the GDPval-AA benchmark.
*   **Complex Environment Interaction:** Maintains 97% skill adherence with over 40 complex skills. Scores 46.3% on Toolathon.
*   **Agent Teams:** Supports native multi-agent collaboration (see [[concepts/agent-teams.md]]).
*   **Character & Emotion:** Improved character consistency and emotional intelligence, enabling applications in interactive entertainment.
