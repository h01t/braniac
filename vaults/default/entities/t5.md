# T5 (Text-to-Text Transfer Transformer)

**Summary**: T5 is an encoder-decoder transformer model that reformulates all NLP tasks into a unified text-to-text format, representing an early and influential large language model.
**Source Context**: Comprehensive Overview of LLMs.pdf.

---

## Key Design Principle
The core innovation of T5 is its "text-to-text" framework. Every task—be it translation, summarization, or classification—is cast as taking a text input and producing a text output. For example, a sentiment classification task might have the input "`sentiment: This movie is great.`" and the target output "`positive`" (Source: Comprehensive Overview of LLMs.pdf, referencing [10]).

## Architecture and Training
T5 uses a standard Transformer [[concepts/transformer-architectures.md|encoder-decoder architecture]]. It was pre-trained on a large web-scraped dataset called C4 using a denoising objective, where spans of text were masked and the model was trained to reconstruct them (Source: Comprehensive Overview of LLMs.pdf, referencing [10]).

## Historical Significance
The paper cites T5 as an example of early work on LLMs that employed transfer learning, where the pre-trained model was fine-tuned on downstream tasks. It helped demonstrate the power of scaling up pre-trained models (Source: Comprehensive Overview of LLMs.pdf, Introduction).
