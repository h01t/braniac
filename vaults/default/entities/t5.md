# T5

**Summary**: An encoder-decoder model that frames every NLP problem as a text-to-text task, using a unified training objective based on masked language modeling.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

**Architecture & Training**: T5 (Text-To-Text Transfer Transformer) is based on the standard Transformer encoder-decoder architecture. A key architectural detail is that it places layer normalization *outside* the residual connections. Its pre-training objective is a variant of **masked language modeling**, where contiguous spans of tokens are replaced with a single sentinel token. This "span corruption" objective produces shorter sequences and speeds up training. After pre-training, T5 can be adapted to downstream tasks via fine-tuning, sometimes using parameter-efficient **adapter layers**.

**Unified Framework**: T5's core innovation is its text-to-text framework. Every task—translation, classification, summarization—is formatted as "input text -> output text." This simplifies the model's training and usage pipeline compared to task-specific architectures.

**Variants**: The **mT5** variant is a multilingual model trained on the mC4 corpus spanning 101 languages. It uses a larger vocabulary (250k tokens) and a tailored data sampling procedure to balance languages and prevent over/under-fitting for any single language.
