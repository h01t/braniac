# T. Dettmers

**Summary**: A researcher known for work on efficient machine learning, particularly model quantization (LLM.int8(), QLoRA) and efficient fine-tuning for large language models.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

T. Dettmers has authored several key papers on making large models more accessible:
* **LLM.int8()** (2022): Introduced 8-bit matrix multiplication for efficient inference of large transformers [[sources/dettmers-et-al-llm-int8-2022.md]].
* **QLoRA** (2023): Combined 4-bit quantization with LoRA for memory-efficient fine-tuning [[sources/dettmers-et-al-qlora-2023.md]].

This body of work is central to [[concepts/model-compression.md]] and [[concepts/training-efficiency-techniques.md]].
