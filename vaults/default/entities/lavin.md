# LaVIN

**Summary**: A multimodal fine-tuning approach that dynamically learns the weights for multimodal features using a mixture-of-modality adapter.
**Source Context**: Comprehensive Overview of LLMs.pdf

---

LaVIN (Language-Vision INstruction tuning) is a method for [[concepts/fine-tuning-for-mllms.md]]. It employs a mixture-of-modality adapter to dynamically learn the weights for multimodal features, enabling parameter-efficient adaptation of a pre-trained LLM [Source: Comprehensive Overview of LLMs.pdf].
